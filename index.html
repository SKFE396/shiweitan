Selected Research

Coder–Tester Co-Evolution (CCE)

CCE jointly trains code and test generators on graded optimization tasks. Execution feedback guides the code generator, and rewards based on test reliability guide the test generator.

Causal Decoding (COAD)

COAD uses causal decoding to reduce hallucinations in multimodal large language models and help ground their outputs in visual inputs.
